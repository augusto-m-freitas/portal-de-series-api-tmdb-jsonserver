# 🎬 Portal de Séries - TMDB & JSONServer

Portal web dinâmico desenvolvido para a disciplina de Desenvolvimento Web na PUC Minas. O projeto consome dados reais da API do The Movie DB (TMDB) para listagem de séries e utiliza um backend mockado com JSONServer para gerenciar o perfil do usuário e suas séries favoritas.

## 🛠️ Tecnologias Utilizadas
* **Front-end:** HTML5, CSS3, JavaScript (Vanilla), Bootstrap
* **Integração de APIs:** Fetch API
* **Back-end/Mock:** JSONServer (Node.js)
* **API de Dados:** The Movie DB (TMDB) API v3

## ⚙️ Funcionalidades
* **Catálogo Dinâmico:** Carrossel de séries populares e cards de lançamentos consumidos diretamente da API do TMDB.
* **Sistema de Busca:** Pesquisa em tempo real por títulos de séries.
* **Página de Detalhes:** Exibição de sinopse, avaliação e elenco completo (atores e imagens) da série selecionada.
* **Favoritos e Perfil:** Uso do JSONServer (RESTful) para persistir as informações do autor do projeto e permitir que o usuário salve/remova séries da sua lista de favoritas.
